Which voice-clip formats does this WebView play?

Open this page inside the iPad app's WKWebView (copy the folder next to www/index.html and load voice_format_test/index.html), or in Safari on the iPad. Tap Run. Each row tries the two paths the board uses: decodeAudioData (the instant, pre-decoded tap path) and a plain <audio> element (the cold fallback). A format is usable only if both say OK. The Android/web build ships .opus; the iPad copies stay on .mp3 until a row here passes — then switch with write_symbols_data.py (TARGETS ext) + encode_clip.py --all --format <ext> --out ….
